# Maison Ivoire — Bridal Atelier

A luxury bridal studio landing page for a fictional New Delhi atelier, built with Next.js and React.

**Live design direction:** warm ivory, sand, and ink with gold and oxblood accents; editorial typography; slow, quiet motion.

## Stack

- [Next.js 16](https://nextjs.org/) — App Router, Turbopack
- [React 19](https://react.dev/)
- TypeScript
- [lucide-react](https://lucide.dev/) icons
- Custom CSS design system (`app/globals.css`) — no UI framework or Tailwind
- `next/font` — Cormorant Garamond + Jost

## Features

- Art-directed editorial hero and full-length landing page
- Responsive layout for desktop, tablet, and mobile
- Scroll-reveal motion with `prefers-reduced-motion` support
- Gown collection with accessible native `<dialog>` quick views
- Journal cards with full-article reading dialogs
- Appointment request form with client-side validation and success state
- Newsletter capture with inline validation
- SEO metadata, Open Graph / Twitter cards, JSON-LD `LocalBusiness` schema
- `robots.txt` and sitemap generated by Next.js

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev        # start the development server
npm run build      # production build
npm run start      # serve the production build
npm run typecheck  # TypeScript check
```

## Project structure

```
app/
  layout.tsx        # fonts, metadata, skip link
  page.tsx          # landing page sections + JSON-LD
  globals.css       # complete design system
  icon.svg          # favicon
  robots.ts
  sitemap.ts
components/
  Header.tsx        # sticky nav + mobile menu
  Collection.tsx    # gown cards + quick-view dialog
  Journal.tsx       # journal cards + article dialog
  AppointmentForm.tsx
  NewsletterForm.tsx
  Footer.tsx
  MotionController.tsx
  Brand.tsx
lib/
  content.ts        # gowns, journal entries, process, appointment types
public/images/      # local, art-directed photography
```
